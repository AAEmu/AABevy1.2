The early 0x065 and the 0x042 are byte-identical to the 1.2 manual session on

Gaps
----
* 0x043 CSSpecialtyRatio: known follow-up. The Bevy replay invokes
  X2Store:SellBackPackGoods() directly, so it does not open the quote request;
  the server still walks the same 0x042 sale path.
* 0x052 CSStartSkill for 25205: 1.2 sends it (skill 25205, caster 39112 the
  player, target 39124 the trader). Bevy has no CSStartSkill path for 25205
  and sends none; the server still completes the sale.
* 0x068 body: the replay drives a programmatic right click (extra_info 0,
  mouse_button 2), while 1.2 uses 1/3 for the same talk; opcode and order
  match, and this is not on the sale path.

An earlier run on a hand-seeded character whose stored name is not normalized
was refused with MAIL_UNKNOWN_FAILURE; a valid 1.2 name sells.
