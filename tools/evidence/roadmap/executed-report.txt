Getter39443a70, exact observable contract
========================================
1. It retrieves category5/common_server_data_1 and section roadmap_option.
   Absent section OR section with no child nodes -> zero results (Lua nil).
   A nonempty section with no recognized readable field -> an empty Lua table.
   There is no getter-side default size/visible/NPC injection.
2. HasIntAttribute(size) success -> signed i32 local [ebp-18].
   Native390309f0 does CVTSI2SS -> ScriptAny tag4 (Lua number), so number output

Actual Data bool semantics (33005210 ->3301bc00)
===============================================
HasBoolAttribute fails for a missing attribute or an attribute with no value
child, and leaves the output byte unchanged (fixture0xaa stayed0xaa).
A present child containing EMPTY quoted string is different: success, false.
A present nonempty invalid token also succeeds, false. HasBoolAttribute's bool
return indicates the value leaf exists; it does not validate boolean spelling.
Only exact lowercase "true" decodes true. Tested "false", "1", "0", "TRUE",
"False", "yes", "-1", "2", "", "garbage" all successfully decode false.
For multiple value children it uses the first (false,true yieldedfalse).
Consequently invalid/empty NPC text WITH known size still triggers numeric NPC
output, since the getter tests HasBoolAttribute success rather than parsed truth.

Setter39443bc0, exact field / Data contract
==========================================
* Missing section is created, then the selected roadmap_option section is
  UNCONDITIONALLY CLEARED. Input is replacement, not a field merge. Unknown or
  omitted children within that section disappear. Other root-level sections
  survive (fixture other17); no native version field was added by this setter.
* Reads occur in order size, visible, npcShow.
* Given raw ScriptAny field types at the explicit table endpoint, size requires
  numeric tag4; bool/string/nil/table are rejected. Its numeric value is f32,
  then CVTTSS2SI converts to i32 by truncation toward zero. 2.9->2, -1.9->-1.
  16777217 first rounds to f32 16777216. f32 out-of-i32-range converts to
  native integer-indefinite MIN, not Rust's saturating float-as-int result:
  input2147483647 rounds to f32 2147483648, then stores -2147483648.
* visible/npcShow require bool tag2. Numbers0/1/2, strings"true"/"1", nil,
  tables are rejected. There is no numeric-to-bool coercion in these setter
  field branches. Invalid fields are omitted AFTER clearing the old subtree.
  Top-level bad method argument / outer registered binding was not the subject
  of these direct getter/setter entry controls; do not generalize to that ABI.
* Bool writes call actual xlcommon330040c0. The serialized values are literal
  lowercase true / false, NOT1 /0. Example actual SaveToBuffer:
    roadmap_option ( size 2, visible false, npcShow true )\r\n
  Passing {npcShow=3} clears the section and does not add npcShow.
  Passing {} leaves an empty roadmap_option node, whose later getter yieldsnil.
* No immediate save/network operation: all50 setter cases complete with guards
  on39217640 (manager save),39186810 (packet send),397acbb0 (save packet ctor).
  Entering any of them fails the oracle; none entered. Data::SaveToBuffer is
  invoked separately by the research observer to show memory contents, not
  by the original setter. This proves in-memory mutation, not remote durability.

and numeric controls; numeric0 is false, numeric1/2/3 true. It emits event18
